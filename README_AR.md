# بطاقة Mohamed Momo الرقمية

هذه نسخة أولية ثابتة لصفحة شخصية بتصميم أسود وذهبي، مناسبة للفتح من رابط NFC أو QR.

## الملفات
- `index.html`: محتوى الصفحة.
- `style.css`: التصميم والألوان.
- `config.js`: المعلومات التي يمكن تغييرها.
- `app.js`: تشغيل أزرار التواصل.

## تعديل المعلومات
افتح `config.js` واملأ الخانات:
- `phone`: رقم الهاتف بصيغة دولية، مثال `2126XXXXXXXX`.
- `whatsapp`: رقم واتساب بصيغة دولية، بلا `+` وبلا الصفر الأولى.
- `instagram` و`facebook`: رابط الحساب كاملاً.
- `location`: رابط Google Maps.

الخانات الفارغة لا يظهر زرها. لا تضع كلمات مرور أو معلومات حساسة في هذا الملف.

## النشر المجاني
يمكن نشر هذه الملفات كموقع Static على Vercel أو GitHub Pages. بعد النشر، استعمل رابط الموقع نفسه في بطاقة NFC وفي QR Code. عند تحديث `config.js` وإعادة النشر يبقى رابط الصفحة كما هو.

ملاحظة: هذه الحزمة لا تنشر الموقع تلقائياً ولا تسجل دومين؛ النشر يحتاج حساباً عند خدمة الاستضافة.
